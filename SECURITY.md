# Política de Segurança

## Versões com suporte

A branch `main` e o site publicado a partir dela recebem correções de segurança.

## Como relatar uma vulnerabilidade

Não abra uma issue pública para vulnerabilidades que possam afetar visitantes ou colaboradores.

1. Use o recurso **Private Security Advisory** do GitHub neste repositório.
2. Descreva o impacto, os passos para reproduzir e, se possível, uma sugestão de correção.
3. Aguarde a confirmação antes de divulgar detalhes publicamente.

O projeto é um site estático e não coleta dados de estudantes. Mesmo assim, relatos sobre dependências, injeção de conteúdo, cabeçalhos de deploy, supply chain ou vazamento acidental de dados serão analisados com prioridade.
